LIVE IN FIVE COMMANDS.

01 — create the database

npx wrangler d1 create script-vault-db
npx wrangler d1 execute script-vault-db \
  --remote --file=./schema.sql

02 — bind it to pages

Dashboard → Pages → your project →
Settings → Bindings → D1 database
Variable name:  DB   ← must be exactly "DB"

03 — deploy

npx wrangler login
npx wrangler pages deploy . \
  --project-name=script-vault

REST API (built in)

GET/api/scriptslist all
POST/api/scriptscreate
GET/api/scripts/:idfetch + count view
PUT/api/scripts/:idupdate
DEL/api/scripts/:iddelete

Local test

npx wrangler d1 execute script-vault-db \
  --local --file=./schema.sql
